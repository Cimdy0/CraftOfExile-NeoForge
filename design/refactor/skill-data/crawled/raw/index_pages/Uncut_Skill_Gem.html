Uncut Skill Gem

An Uncut Skill Gem is a currency item that can be used to engrave a skill gem or level up an existing skill gem to the level of the Uncut Skill Gem. It is a type of uncut gem.

Item acquisition

Uncut Skill Gem can drop anywhere.
