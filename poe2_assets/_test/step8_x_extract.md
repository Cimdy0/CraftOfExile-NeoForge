## 7. 关键发现

- 字段名中 X 为大写（`X_...`），其对应 `id("...")` 字符串中 X 为小写（`x_...`）——同一 token 两形态。
- 「前」类（X_ 前缀）是主体；「中」类（`_X_`）多为多数值占位（如 `..._PER_X_...`、`..._X_OF_...`）。
- 「末」类（_X 后缀）在当前代码库中几乎不存在（命名约定未采用后缀形式）。
- `{X}` 仅存于源语料 `stat_templates.txt`，是生成 X_ 常量名的源头；落地后 Java 层已无 `{X}` 字面量。
